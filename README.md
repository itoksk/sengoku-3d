# 戦国合戦 3D俯瞰デモ

three.js（r128, CDN）で作った、戦国時代の合戦を3Dで俯瞰する授業用デモです。ビルド不要の静的HTMLなので、GitHub Pages でそのまま公開できます。

- `suwahara/` 諏訪原城の戦い（1575）
- `sekigahara/` 関ヶ原の戦い（1600）

## 操作
- ドラッグ：視点の回転／ホイール・ピンチ：拡大縮小／ダブルクリック：視点リセット
- Space：再生・停止／← →：場面移動

## ローカルで確認
```
python3 -m http.server 8000
```
で http://localhost:8000 を開きます。

## 注意
通説にもとづく概念的な再現です。地形の縮尺、軍勢の数・配置には演出が含まれます。
